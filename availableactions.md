# This List Displays all available actions Vanta can perform on your computer.
<small>This list will be updated accordingly as more updates are released</small>

* ram_usage: checks the current RAM usage (requires no confirmation)
* time: gets the current local Windows time (time requires no confirmation)
* wifi_status: checks the current Wi-Fi connection status (requires no confirmation)
wifi_status checks the local Wi-Fi adapter, Wi-Fi connection,
network name (SSID), and link speed.
* internet_status: checks whether the PC currently has an active internet connection (requires no confirmation)
* open_app: launches a Windows application by name or path. (requires confirmation)
* close_app: close a Windows application by name or executable (requires confirmation)
* close_vanta: close the Vanta desktop application. (requires confirmation)
* flip_coin: flips a virtual coin and displays an animated coin flip in the Vanta UI. The coin will randomly land on Heads or Tails, display the result, and then disappear. (requires no confirmation)
* open_url: opens a web URL. (requires confirmation)
* mute_mic: mute or unmutes the microphone through the Vanta app. (requires no confirmation)
* volume: sets Windows master volume percentage (0-100) (requires confirmation)
* type_text: types text into the currently focused application. (requires confirmation)
* shell: run a Windows command (requires confirmation)
